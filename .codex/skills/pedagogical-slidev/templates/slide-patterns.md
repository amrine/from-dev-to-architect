# Slide pattern templates

## Situation

```text
Title: a concrete question or consequence
Context: actor + trigger
Friction: observable symptom
Conclusion: why the learner must continue
```

## Comparison

```text
Question: which option fits this constraint?
Option A: benefit / cost
Option B: benefit / cost
Decision: chosen option and criterion
Accepted compromise: what we give up
```

## Proof

```text
Guarantee: expected behavior
Evidence: observed result
Mechanism: test, command, log, response, or database state
Conclusion: why this evidence is sufficient
```

## Architecture

```text
Problem: what boundary is needed?
Diagram: ownership and direction
Legend: unfamiliar symbols
Conclusion: how the structure answers the problem
```
