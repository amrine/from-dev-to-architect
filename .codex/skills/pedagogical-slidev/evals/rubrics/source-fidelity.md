# Eval rubric: Source fidelity

- Every important claim has a source or explicit interpretation label.
- Besoin files are authoritative for ticket details.
- ADRs are authoritative for architecture decisions.
- Committed code is authoritative for implemented behavior.
- Excel is used for ordering and complementary roadmap context.
- Conflicts are reported rather than silently merged.
- Missing ADRs are visible and never fabricated.
- Scope and non-scope are preserved.
- Planned, implemented, validated, and deferred states remain distinct.
